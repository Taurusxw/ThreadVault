# ThreadVault Documentation

This directory is the Markdown source of truth for ThreadVault planning, usage, contracts, and historical development records.

## Current Guides

- `THREADVAULT_USAGE_MANUAL.md` - user-facing CLI usage manual.
- `development-progress.md` - chronological development log.
- `v4/` - active v4 Personal Web UI development records.
- `v3/` - active v3 richer clients and team governance development records.
- `v2/` - active v2 retrieval and interfaces development records.
- `v1/` - accepted v1 personal knowledge layer development records.
- `roadmap/` - major-version roadmap for v1 and beyond.
- `schemas/` - packaged JSON Schema contract artifacts generated by ThreadVault.

## Historical Archives

- `v0/` - standardized archive for the completed v0 CLI/data-layer development line.
- `archive/` - related research appendices that are not part of the active ThreadVault product plan.

## v3 Starting Point

Before starting each v3 implementation round, read:

1. `roadmap/major-version-roadmap.md`
2. `roadmap/v3-clients-and-team-governance.md`
3. `v3/README.md`
4. `v2/README.md`
5. `v2/phases/phase-07-v2-acceptance-smoke/v2-acceptance.md`
6. `development-progress.md`

v3 work should build richer clients and optional team governance on top of the accepted v2 retrieval, hybrid retrieval,
vector adapter, and agent-facing interface contracts. Do not recreate `deep-research-report.md`; keep phase detail under
`docs/v3/` and chronological updates in `development-progress.md`.
