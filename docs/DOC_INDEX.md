## Reading Paths

For ordinary usage:

1. `README.md`
2. `docs/THREADVAULT_USAGE_MANUAL.md`
3. `docs/MCP_INTEGRATION.md` if connecting an MCP client.
4. `docs/API.md` if using JSON contracts, MCP, or retired interface metadata.

For implementation:

1. `AGENTS.md`
2. `CONTEXT.md`
3. `docs/RULES.md`
4. `docs/ARCHITECTURE.md`
5. `docs/KNOWLEDGE_GRAPH.md`
6. The relevant module and tests.

For debugging path confusion:

1. `README.md` "Important Paths"
2. `docs/DATABASE.md`
3. `docs/API.md` health route section.

## Migration Note

The legacy `docs/v0` through `docs/v4` directories and `docs/development-progress.md` were migrated to `docs/progress/archive/` after user confirmation. Their internal historical filenames are preserved as archive evidence; new development records must use `docs/progress/rounds/`, `docs/progress/phases/`, or the standard documents above.
